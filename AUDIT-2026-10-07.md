# FloodGuard audit — 7 October 2026

Scope: current frontend and backend source; Render deployment/logs; read-only Supabase integrity/access review; existing regression tests and model validation. No production records were created, edited or deleted during testing.

## Fixes

- Preserve missing weather/elevation as unknown, validate complete rainfall forecasts, and format Vietnam forecast timestamps independently of browser timezone.
- Prevent late requests from replacing a newer selected map point; bound requests; clear stale metrics on failure; update weather after dragging the marker.
- Bound backend weather/elevation caches, including successful provider responses.
- Refresh scripts/styles, isolate navigation cache keys, preserve healthy offline pages during HTTP 5xx, avoid caching API responses, and keep unrelated service-worker caches intact.
- Handle blocked browser storage without stopping theme/heatmap initialization.
- Remove duplicate navigation to nonexistent live.html.
- Serialize backend incident snapshots to prevent out-of-order writes; disable missing/default legacy operator keys; require verified admin email for street observations; bound watchlist auth/preferences requests.
- Repair stale test expectations for the 21-page editor catalog and voucher detail workflow; include unit/DOM tests in CI.

## Verified data

- All 19 public tables have RLS enabled. Public RPCs are not executable by anon/authenticated clients; service_role is the intended backend access path. Missing client policies on backend-only tables are not grounds to open access.
- Four reports have four JPEG data-URI photos stored in PostgreSQL (397,392 total characters); no invalid coordinate, prefix or size found in this sample. No Storage bucket is currently used.
- Two persisted SOS incidents have token digests. No live street-depth observations are present.
- Model audit reproduced: 48 core pairs, 8 independent dates, 21 streets. Grouped-date evaluation: 13/48 covered, MAE 14.44 cm versus baseline 13.02 cm. Forward-time evaluation: only 1/35 covered. These results do not establish reliable current street-depth prediction.

## Limits

Local browser downloads were blocked by an invalid download response, so local rendered mobile/browser suites could not run. Logic/DOM tests passed; CI browser results must be checked separately. Public production homepage and alerts were inspected in the browser. Authenticated end-to-end SOS, real camera hardware, email delivery and real voucher redemption were not exercised. Supabase leaked-password protection remains disabled and requires a separate account setting review. Render backend uses a free instance; always-on scheduled email delivery is not verified by a healthy HTTP endpoint.
